# Changelog

## 1.0.0

- Added the Social Discovery classic theme foundation.
- Added modular setup, enqueue, Customizer, compatibility, navigation, header, footer, content, and template files.
- Added responsive header layouts, mobile drawer navigation, sticky header, and light/dark/system mode foundation.

## 1.1.0

- Added modular native homepage builder and allowlisted section ordering.
- Added configurable hero, community, people, interests, discussions, benefits, guidelines, articles, CTA, FAQ, and contact sections.
- Added WordPress and BuddyPress-safe public content sources with empty-state hiding.
- Added homepage Customizer panel and Elementor-compatible page templates.
- Added responsive homepage styles and lightweight interactions.

## 1.2.0

- Added native WordPress authentication templates and secure companion-plugin handlers.
- Added registration, login, password recovery, and reset-password flows.
- Added multi-step onboarding with progress, profile, interest, privacy, and completion screens.
- Added member profile, account settings, profile visibility, and header account navigation.
- Added BuddyPress-safe profile, avatar, public activity, and activation integration points.

## 1.3.0

- Added BuddyPress-backed social feed, composer, public activity cards, filters, favorites, and comments foundation.
- Added member discovery and directory templates with search, sorting, interest filters, and deterministic recommendations.
- Added Friends-component connection actions and saved-activity references in Social Discovery Core.
- Added REST API permission checks, rate limits, and responsive social UI assets.

## 1.4.0

- Added BuddyPress Groups directory, details, activity, membership actions, and My Communities template.
- Added BuddyPress Private Messaging inbox, conversations, compose, reply, and message-state foundation.
- Added guarded companion-plugin permissions and REST handlers for group membership and private messages.
- Added responsive community and messaging styles, scripts, Customizer settings, and documentation.

## 1.5.0

- Added authenticated Member Dashboard, Personal Workspace, profile completion, summary cards, quick actions, and saved-content preview.
- Added BuddyPress-aware Notification Center, unread count, filters, notification ownership checks, and mark-read actions.
- Added dashboard Customizer settings and responsive dashboard, notification, and workspace assets.
- Added companion-plugin dashboard aggregation and notification REST foundations.

## 1.6.0

- Added companion-plugin report, report-action, block, restriction, and audit-log schema with idempotent migration.
- Added least-privilege moderation capabilities and Social Discovery admin control center pages.
- Added authenticated report/block frontend controls and protected REST endpoints.
- Added WordPress personal-data exporter and eraser integrations plus safety settings.
